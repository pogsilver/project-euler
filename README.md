# Project Euler Solutions

An ongoing collection of [Project Euler](https://projecteuler.net/about) solutions in Python, currently covering problems 1–30. Project Euler's own rules permit sharing solutions for the first 100 problems, so new solutions will keep being added here up to that point.

## Structure

One script per problem, `problem_N.py`, split across folders by decade to mirror Project Euler's own numbering:

- `problems_1_to_10/`
- `problems_11_to_20/`
- `problems_21_to_30/`

Future problems follow the same convention (`problems_31_to_40/`, and so on).

A handful of problems that operate on a provided dataset ship the input alongside the script (`problem_8.txt`, `problem_11.txt`, `problem_13.txt`, `problem_18.txt`, `problem_22.txt`) — each script locates its data file relative to its own path, so it runs correctly regardless of your current working directory.

## Requirements

Python 3, standard library only, **except** for a few problems that lean on the [`primefac`](https://pypi.org/project/primefac/) package for prime generation and factorization:

```bash
pip install primefac
```

Needed by: `problem_3`, `problem_7`, `problem_10`, `problem_12`, `problem_27`.

## Running a solution

```bashHere is the first batch out of 3 batches - wait until I tell you that I have uploaded all batches
python problem_N.py
```

Each script prints its answer to stdout.

## Problems 1–10

| # | Problem | Approach |
|---|---|---|
| 1 | Sum of all multiples of 3 or 5 below 1000 | Direct summation |
| 2 | Sum of even Fibonacci terms below four million | Iterative Fibonacci generation |
| 3 | Largest prime factor of 600,851,475,143 | Factorization via `primefac` |
| 4 | Largest palindrome from the product of two 3-digit numbers | Descending search with early-exit pruning once products fall below the current best |
| 5 | Smallest number evenly divisible by 1–20 | Iterative LCM |

| 7 | The 10,001st prime number | `primefac`'s prime generator |
| 8 | Largest product of 13 adjacent digits in a 1000-digit number | Sliding window that updates the running product incrementally instead of recomputing it |
| 9 | The product `abc` of the Pythagorean triplet with `a+b+c=1000` | Derived via Euclid's parametrization of primitive triples, not brute force over `a`, `b`, `c` |
| 10 | Sum of all primes below two million | `primefac`'s prime generator |

## Problems 11–20

| # | Problem | Approach |
|---|---|---|
| 11 | Largest product of four adjacent numbers in a 20×20 grid | Checks rows, columns, and both diagonals |
| 12 | First triangular number with over 500 divisors | Exploits the divisor-count function's multiplicativity over a triangular number's two coprime factors, avoiding factoring the (large) triangular number directly |
| 13 | First 10 digits of the sum of 100 fifty-digit numbers | Sums only the leading 12 digits of each number — enough to bound the maximum possible carry |
| 14 | Starting number under one million with the longest Collatz chain | Memoizes chain lengths so shared suffixes aren't recomputed |
| 15 | Number of lattice paths across a 20×20 grid | Recognized as the binomial coefficient `C(40,20)` rather than a DP grid walk |
| 16 | Sum of the digits of 2¹⁰⁰⁰ | Solved both with Python's native big integers and with a from-scratch square-and-multiply big-number multiplication |
| 17 | Total letters used writing 1–1000 in English words | Precomputed word-length lookup table |
| 18 | Maximum-sum root-to-base path through a number triangle | Bottom-up dynamic programming |
| 19 | Sundays falling on the first of the month, 1901–2000 | Manual day-of-week counter (no `datetime`) |
| 20 | Sum of the digits of 100! | Native big integers, plus the same from-scratch big-number multiplication as problem 16 |

## Problems 21–30

| # | Problem | Approach |
|---|---|---|
| 21 | Sum of all amicable numbers under 10,000 | Sieve computing divisor sums for every number in one pass |
| 22 | Sum of position-weighted alphabetical name scores | Reads and sorts the provided name list |
| 23 | Sum of positive integers that can't be written as the sum of two abundant numbers | Reuses the divisor-sum sieve from problem 21 |
| 24 | The one-millionth lexicographic permutation of 0–9 | Computed directly via the factorial number system, not by generating permutations |

| 27 | Coefficients maximizing consecutive primes generated by `n² + an + b` | Narrows the search using primality/parity constraints on `a` and `b` |
| 28 | Sum of both diagonals of a 1001×1001 number spiral | Closed-form per-ring formula instead of building the grid |
| 29 | Distinct values of `a^b` for 2 ≤ a, b ≤ 100 | Set comprehension |

## Notable approaches

A few solutions go beyond a direct brute-force search:

- **Problem 9** uses Euclid's formula for primitive Pythagorean triples to search over parameters instead of iterating every `(a, b, c)`.
- **Problem 12** exploits the fact that a triangular number's two factors (`n` and `n+1`, or their halves) are coprime, so their divisor counts can be computed separately and multiplied — avoiding factoring a potentially huge number directly.
- **Problem 14** memoizes Collatz sequence lengths across all starting values, turning what could be a lot of repeated work into a single pass with cached results.
- **Problems 16 and 20** each include a from-scratch square-and-multiply big-integer multiplication, implemented alongside the native-bigint one-liner — a nice side-by-side of "the Python way" and "the general algorithm."
- **Problem 24** computes the millionth permutation directly through the factorial number system, rather than generating and indexing into all 10! permutations.
- **Problem 28** derives a closed-form formula for each ring of a number spiral, avoiding building the 1001×1001 grid at all.
